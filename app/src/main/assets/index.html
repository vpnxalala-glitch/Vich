Готов к работе
Привет! Я AI Chat. Добавь API-ключ в настройках и выбери модель. Также доступны команды управления телефоном: /open название приложения, /settings wifi, /phoneinfo.

Настройки API

Ключ хранится локально на устройстве в хранилище приложения. Не вставляй чужие ключи и не публикуй их. Запросы отправляются напрямую выбранному API-провайдеру.

Команды телефона

/open WhatsApp — открыть приложение по названию
/settings wifi — Wi-Fi
/settings bluetooth — Bluetooth
/settings display — экран
/settings sound — звук
/settings location — геолокация
/settings apps — настройки приложений
/phoneinfo — сведения об устройстве
