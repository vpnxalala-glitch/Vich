# AI Chat для Android

Android-порт AI Chat Desktop. В приложении сохранён чат-интерфейс и добавлен ограниченный Android-мост для открытия приложений, системных настроек и просмотра сведений об устройстве.

## Возможности
- API-провайдеры, указанные в интерфейсе приложения.
- История чатов и настройки в локальном хранилище WebView.
- Открытие приложений по названию через Android launcher.
- Переход в Wi-Fi, Bluetooth, экран, звук, геолокацию и настройки приложений.
- Информация об устройстве.

## Сборка
GitHub Actions собирает debug APK на каждый push в `main` и по ручному запуску. APK прикрепляется к GitHub Release и сохраняется как Actions artifact.

## Ограничения Android
Приложение не выполняет произвольные shell-команды и не получает скрытый доступ к другим приложениям. Для защищённых функций Android требуется системное разрешение или подтверждение пользователя.

## Безопасность API
API-ключи вводятся пользователем в приложении. Не добавляйте ключи в исходный код или GitHub.
